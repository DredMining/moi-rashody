# Мои расходы

Личный учёт доходов и расходов: лимит на месяц, командировочные отдельно, карты и наличка, процент на брокер, долги, сравнение месяцев.

Это один файл `index.html` без сервера. Записи хранятся только в браузере устройства, на котором вы открываете сайт; на GitHub они не попадают.

## Как включить сайт

1. Settings → Pages.
2. Source: **Deploy from a branch**, ветка **main**, папка **/ (root)** → Save.
3. Через минуту сайт будет по адресу `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

## На телефон

Откройте адрес и добавьте на главный экран:
- iPhone, Safari: «Поделиться» → «На экран „Домой“».
- Android, Chrome: меню ⋮ → «Добавить на главный экран».

Открывайте приложение с этой иконки, а не из вкладки браузера: так браузер не удалит записи.

## Резервная копия

Вкладка «Деньги» → «Данные и резервная копия» внизу: «Скачать резервную копию» сохраняет записи, долги и настройки в файл `.json` (на iPhone откроется меню «Поделиться» — выберите «Сохранить в Файлы»), «Загрузить резервную копию» восстанавливает их (например, на новом телефоне). Делайте копию раз в неделю (если её не было больше недели, на «Учёте» появится напоминание) и сохраняйте в iCloud Drive: «Поделиться» → «Сохранить в Файлы» → iCloud Drive — так копия уцелеет, даже если потерять телефон. Записи живут только на этом телефоне, и если удалить иконку приложения, они удалятся вместе с ней.
