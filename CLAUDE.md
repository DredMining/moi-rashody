# Мои расходы

Личное веб-приложение учёта доходов и расходов (PWA, GitHub Pages: DredMining/moi-rashody).
Владелец — Али. Общаться по-русски, на «ты», коротко и по делу.

## Устройство проекта
- Всё приложение — один файл `index.html` (~390 КБ): HTML, CSS и JavaScript внутри. Сервера нет.
- `iphone.html` — страница-рамка iPhone для предпросмотра.
- `sw.js` — service worker (офлайн). `manifest.webmanifest` — установка на главный экран.
- Данные хранятся только в localStorage браузера (ключ `expenses-v1`). Резервная копия — файл .json.
- `AUDIT_REPORT*.md` — отчёты аудита логики. Читать перед правками, касающимися денег, дат и копеек.
- `.worktree-iphone-safe-area/` — рабочая копия ветки, не трогать.

## Правила работы
- Код и файлы проекта не менять без явного подтверждения Али. Сначала показать, что и где поменяется.
- Не коммитить и не пушить без команды. Никаких force-push.
- Перед правкой читать актуальную версию файла, а не пересказ.
- Не трогать формат данных в localStorage без миграции: у владельца там реальные записи.
- Деньги: считать в копейках (целые числа), не в float. Даты и часовой пояс проверять отдельно.
- Дизайн по умолчанию тёмный. Интерфейс на русском.
- Не выдумывать цифры, ссылки и факты. Отмечать, что проверено, а что предположение.

## Бизнес-правила приложения
- 10% обычного дохода уходит на брокерский счёт. Командировочные не считаются, пока командировка идёт; остаток после «Командировка закончилась» становится личным доходом, и с него 10% берутся.
- Лимит личных трат — 30 000 ₽ в месяц.
- Командировочные учитываются отдельно: важно, сколько осталось, а не с какого счёта потрачено. Напоминание о возврате личных денег не нужно.

## Проверка
- Предпросмотр: Live Server (правый клик по index.html → Open with Live Server).
- После правок проверять консоль браузера на ошибки и работу офлайн (sw.js).
- Версия кэша в sw.js должна меняться при каждом изменении index.html.

## Субагенты (в .claude/agents/)
- `architect` — структура и качество кода, только читает.
- `ui-auditor` — дизайн, шрифты, отступы, адаптивность, только читает.
- `tester` — ошибки JavaScript и регрессии, только читает.
Агенты ничего не редактируют: правки вносит основной Claude по команде Али, по одному файлу за раз.
